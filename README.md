# AI Study Buddy

An AI-powered study assistant that turns class notes into explanations,
practice quizzes, and flashcards.

# Features

- Explains concepts using notes
- Generates practice quizzes
- Generates flashcards
- Uses the OpenAI API
- Builds with Streamlit

# Tech Stack

- Python
- Streamlit
- OpenAI API
- Git / GitHub

# How It Works

1. The user enters their study notes
2. The user chooses a study mode
3. The app sends the notes and request to an AI model
4. The AI generates a study resource based on the provided notes
